# 實測紀錄（TESTLOG）

> 這份檔案**由實測的人填寫**。每次照 `labs/` 的說明從頭實測一遍，就新增一筆紀錄。
> 開課前重測時，可以對照之前發現過的問題。

## 實測檢查項目（每次都逐項確認）

- [ ] 每個 gcloud 指令都能直接複製執行，沒有錯字或缺少的參數
- [ ] 每個步驟寫的「預期看到的結果」和實際畫面一致
- [ ] Console 的選單位置和按鈕名稱與現行介面相符
- [ ] 指定的角色足以完成操作，沒有權限不足的錯誤
- [ ] 這一段的費用在預期內
- [ ] 這一段建立的資源，用清理指令都能刪乾淨
