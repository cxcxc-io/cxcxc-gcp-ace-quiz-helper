# 2. 先照做：打包小幫手

> 對應講義：Compute Engine 虛擬機器 → Lab 實作 →「先照做：打包小幫手」
>
> 先完成 [0-開始前](0-開始前.md)。

## 開始前：確認 Cloud Shell 在你的專案

講義沒有對應的 Console 動作。Cloud Shell 不一定停在這門課的專案（重開 Cloud Shell、從別的專案頁面打開、或之前切換過專案都可能），所以每一份都先執行這一段，順便把這一份要用的變數設好。

```bash
gcloud config set project "你的專案ID"
export PROJECT_ID=$(gcloud config get-value project)
export REGION=asia-east1
export IMAGE=${REGION}-docker.pkg.dev/${PROJECT_ID}/quiz-helper/quiz-helper:v1
echo "目前專案：${PROJECT_ID}"
```

- `"你的專案ID"`：換成你的專案 ID（Console 上方的專案選單看得到），雙引號保留

**你應該會看到**：`Updated property [core/project].`，接著印出你的專案 ID。出現 `WARNING: You do not appear to have access to project` 代表專案 ID 打錯了。

## 步驟 1：啟用 Artifact Registry 與 Cloud Build 的 API

對應講義：進 Artifact Registry 時按「啟用」、在程式庫啟用 Cloud Build API。

```bash
gcloud services enable artifactregistry.googleapis.com cloudbuild.googleapis.com
```

**你應該會看到**：`Operation "operations/..." finished successfully.`

## 步驟 2：建立存放區

對應講義：「建立存放區」，名稱 quiz-helper、格式 Docker、區域 asia-east1。

```bash
gcloud artifacts repositories create quiz-helper \
  --repository-format=docker \
  --location=${REGION} \
  --description="考題小幫手映像檔"
```

- `--repository-format=docker`：存放的是容器映像檔
- `--location`：存放區的區域，跟 VM 放在同一區，拉取比較快

**你應該會看到**：`Created repository [quiz-helper].`

## 步驟 3：用 Cloud Build 打包並推送

對應講義：在 Cloud Shell 執行打包指令（只有指令）。

```bash
cd ~/cloudshell_open/cxcxc-gcp-ace-quiz-helper
gcloud builds submit --tag ${IMAGE} .
```

- `gcloud builds submit`：把目前資料夾的程式碼上傳給 Cloud Build，在雲端照 `Dockerfile` 打包
- `--tag ${IMAGE}`：打包完推送到這個名稱
- 最後的 `.`：代表「目前這個資料夾」

**你應該會看到**：持續印出建置過程，最後一個表格的 `STATUS` 是 `SUCCESS`。

### 常見卡關：出現 `PERMISSION_DENIED`

打包時用的不是你的權限，而是 Cloud Build 的建置服務帳戶；較新的專案預設用 Compute Engine 預設服務帳戶。上一份步驟 4 如果查不到任何角色，這裡就會卡住。補上 Cloud Build 需要的角色再打包一次：

```bash
export PROJECT_NUMBER=$(gcloud projects describe ${PROJECT_ID} --format="value(projectNumber)")
gcloud projects add-iam-policy-binding ${PROJECT_ID} \
  --member="serviceAccount:${PROJECT_NUMBER}-compute@developer.gserviceaccount.com" \
  --role="roles/cloudbuild.builds.builder" \
  --condition=None --format=none
gcloud builds submit --tag ${IMAGE} .
```

- `roles/cloudbuild.builds.builder`：執行建置需要的角色，包含讀取上傳的程式碼、推送映像檔、寫入建置紀錄

## 步驟 4：確認映像檔在存放區裡

對應講義：Artifact Registry 的 quiz-helper 存放區裡有 quiz-helper，標記 v1。

```bash
gcloud artifacts docker images list ${REGION}-docker.pkg.dev/${PROJECT_ID}/quiz-helper --include-tags
```

- `--include-tags`：一併顯示標記

**你應該會看到**：一列 `quiz-helper`，`TAGS` 欄位是 `v1`。
