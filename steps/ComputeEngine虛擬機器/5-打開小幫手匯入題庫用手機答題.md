# 5. 打開小幫手，匯入題庫，用手機答題

> 對應講義：Compute Engine 虛擬機器 → Lab 實作 →「打開小幫手，匯入題庫，用手機答題」

## 步驟 1：取得 VM 的外部 IP

對應講義：在 VM 執行個體清單點「外部 IP」。

```bash
export VM_IP=$(gcloud compute instances describe quiz-helper-vm --zone=${ZONE} \
  --format="value(networkInterfaces[0].accessConfigs[0].natIP)")
echo "小幫手網址：http://${VM_IP}"
```

- `--format="value(networkInterfaces[0].accessConfigs[0].natIP)"`：從 VM 的設定裡取出第一張網卡的外部 IP

**你應該會看到**：`小幫手網址：http://<一組 IP>`

## 步驟 2：確認小幫手活著

對應講義：打開網址看到「考題小幫手」頁面。

```bash
curl -s http://${VM_IP}/healthz
```

- `/healthz`：小幫手的健康檢查網址，正常會回傳狀態與版本

**你應該會看到**：`{"status":"ok","version":"v1"}`。剛建好的 VM 要一兩分鐘才會啟動完成，沒有回應就等一下再試。

### 常見卡關：一直沒有回應

```bash
gcloud compute instances get-serial-port-output quiz-helper-vm --zone=${ZONE} | grep "quiz-helper"
```

- `get-serial-port-output`：讀出 VM 開機時印在序列埠的訊息，開機指令碼的輸出也在這裡

**你應該會看到**：「準備執行 ...」和「容器已啟動」。

- 有「容器已啟動」：小幫手正常，回頭檢查上一份步驟 1 的防火牆規則與 `http-server` 標記
- 拉取映像檔失敗：檢查 IAM 章授予的 Artifact Registry 讀取者，以及 `IMAGE` 變數是否正確

## 步驟 3：匯入題庫、用手機答題

這一步用瀏覽器做，跟講義相同：

1. 打開 `http://<VM 的 IP>/admin`，按 `questions.csv` 旁的「匯入」
2. 用手機打開 `http://<VM 的 IP>`，輸入暱稱開始答題
