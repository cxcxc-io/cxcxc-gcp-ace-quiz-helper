# 7. 查詢中繼資料

> 對應講義：Compute Engine 虛擬機器 → Lab 實作 →「查詢中繼資料」

中繼資料伺服器的網址固定是 `http://metadata.google.internal/computeMetadata/v1/`，只有在 VM 裡面查得到，而且每個請求都要帶上標頭 `Metadata-Flavor: Google`。

## 開始前：確認 Cloud Shell 在你的專案

講義沒有對應的 Console 動作。Cloud Shell 不一定停在這門課的專案（重開 Cloud Shell、從別的專案頁面打開、或之前切換過專案都可能），所以每一份都先執行這一段，順便把這一份要用的變數設好。

```bash
gcloud config set project "你的專案ID"
export PROJECT_ID=$(gcloud config get-value project)
export ZONE=asia-east1-b
echo "目前專案：${PROJECT_ID}"
```

- `"你的專案ID"`：換成你的專案 ID（Console 上方的專案選單看得到），雙引號保留

**你應該會看到**：`Updated property [core/project].`，接著印出你的專案 ID。出現 `WARNING: You do not appear to have access to project` 代表專案 ID 打錯了。

## 步驟 1：連進 VM

```bash
gcloud compute ssh quiz-helper-vm --zone=${ZONE}
```

## 步驟 2：先設一個縮寫，少打一點字

```bash
MD="curl -s -H Metadata-Flavor:Google http://metadata.google.internal/computeMetadata/v1"
```

- `-H Metadata-Flavor:Google`：中繼資料伺服器要求的標頭，沒帶會被拒絕，避免程式被騙去讀取

## 步驟 3：我叫什麼、在哪裡

對應講義：Console 的 VM 名稱與可用區。

```bash
$MD/instance/name; echo
$MD/instance/zone; echo
```

- `instance/name`：VM 的名稱
- `instance/zone`：所在可用區，格式是 `projects/<專案編號>/zones/asia-east1-b`
- `; echo`：補一個換行，畫面比較整齊

**你應該會看到**：`quiz-helper-vm`，以及結尾是 `asia-east1-b` 的可用區。

## 步驟 4：要跑哪個映像檔

對應講義：Console 中繼資料區塊的 `quiz-helper-image`。

```bash
$MD/instance/attributes/quiz-helper-image; echo
```

- `instance/attributes/鍵名`：讀出自訂中繼資料。開機指令碼 `startup.sh` 第 1 步就是用這一行讀出映像檔名稱

**你應該會看到**：`asia-east1-docker.pkg.dev/<專案 ID>/quiz-helper/quiz-helper:v1`，跟 Console 上的一樣。

## 步驟 5：我用哪個身分

對應講義：Console VM 詳細資料的「服務帳戶」。

```bash
$MD/instance/service-accounts/default/email; echo
```

- `service-accounts/default/email`：附加在這台 VM 上的服務帳戶

**你應該會看到**：`quiz-helper@<專案 ID>.iam.gserviceaccount.com`。小幫手讀 Firestore、讀值區時，用的就是這個身分。

## 步驟 6：離開 VM

```bash
exit
```
