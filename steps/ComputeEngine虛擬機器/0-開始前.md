# 0. 開始前：切到這一章的版本、設定變數

> 對應講義：Compute Engine 虛擬機器 → Lab 實作（每次新開 Cloud Shell 都先做這一份）

這一章要用到開機指令碼 `deploy/vm/startup.sh`，它在 `lab-1` 這個版本才有，所以先切過去。

## 步驟 1：切到 lab-1

講義沒有對應的 Console 動作。

```bash
cd ~/cloudshell_open/cxcxc-gcp-ace-quiz-helper
git fetch --tags --force
git checkout lab-1
ls deploy/vm/
```

- `git checkout lab-1`：切到這一章用的程式碼版本
- `ls deploy/vm/`：確認開機指令碼在裡面

**你應該會看到**：`quiz-helper-bucket-role.yaml  startup.sh`

## 步驟 2：設定這一章會用到的變數

```bash
gcloud config set project <你的專案 ID>
export PROJECT_ID=$(gcloud config get-value project)
export REGION=asia-east1
export ZONE=asia-east1-b
export SA_EMAIL=quiz-helper@${PROJECT_ID}.iam.gserviceaccount.com
export BUCKET=${PROJECT_ID}-gcp-ace-cxcxc
export IMAGE=${REGION}-docker.pkg.dev/${PROJECT_ID}/quiz-helper/quiz-helper:v1
echo "${PROJECT_ID} ${ZONE} ${SA_EMAIL} ${IMAGE}"
```

- `ZONE`：VM 要放在可用區，不是區域。`asia-east1-b` 是台灣區域裡的一個可用區（回顧講義第 4 節）
- `SA_EMAIL`：IAM 章建立的小幫手服務帳戶
- `BUCKET`：Cloud Storage 章建立的值區
- `IMAGE`：等一下打包出來的映像檔完整名稱，格式是「區域-docker.pkg.dev/專案 ID/存放區/映像檔:標記」

**你應該會看到**：印出專案 ID、`asia-east1-b`、服務帳戶 email、映像檔名稱。

> Cloud Shell 斷線重連後，重新執行這一份即可。
