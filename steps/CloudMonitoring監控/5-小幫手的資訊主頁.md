# 5. 小幫手的資訊主頁

> 對應講義：Cloud Monitoring → Lab 實作 →「小幫手的資訊主頁」
>
> 資訊主頁在 Console 拖拉最直覺。指令版是把同樣的版面寫成 JSON，適合要在多個專案建立相同資訊主頁的時候。

## 步驟 1：把資訊主頁寫成 JSON

```bash
cat > /tmp/quiz-helper-dashboard.json <<'JSON'
{
  "displayName": "考題小幫手",
  "mosaicLayout": {
    "columns": 12,
    "tiles": [
      {"width": 6, "height": 4, "widget": {"title": "CPU 使用率",
        "xyChart": {"dataSets": [{"timeSeriesQuery": {"timeSeriesFilter": {
          "filter": "metric.type=\"compute.googleapis.com/instance/cpu/utilization\" AND resource.type=\"gce_instance\" AND metric.label.\"instance_name\"=\"quiz-helper-vm\"",
          "aggregation": {"alignmentPeriod": "60s", "perSeriesAligner": "ALIGN_MEAN"}}}}]}}},
      {"xPos": 6, "width": 6, "height": 4, "widget": {"title": "網路流量（傳入）",
        "xyChart": {"dataSets": [{"timeSeriesQuery": {"timeSeriesFilter": {
          "filter": "metric.type=\"compute.googleapis.com/instance/network/received_bytes_count\" AND resource.type=\"gce_instance\" AND metric.label.\"instance_name\"=\"quiz-helper-vm\"",
          "aggregation": {"alignmentPeriod": "60s", "perSeriesAligner": "ALIGN_RATE"}}}}]}}},
      {"yPos": 4, "width": 12, "height": 4, "widget": {"title": "運作時間檢查（失敗的地區數）",
        "xyChart": {"dataSets": [{"timeSeriesQuery": {"timeSeriesFilter": {
          "filter": "metric.type=\"monitoring.googleapis.com/uptime_check/check_passed\" AND resource.type=\"uptime_url\"",
          "aggregation": {"alignmentPeriod": "60s", "perSeriesAligner": "ALIGN_NEXT_OLDER", "crossSeriesReducer": "REDUCE_COUNT_FALSE"}}}}]}}}
    ]
  }
}
JSON
```

- `mosaicLayout`：資訊主頁的版面，寬度分成 12 格；每個 `tile` 用 `xPos`、`yPos`、`width`、`height` 決定位置與大小
- `filter`：跟 Metrics Explorer 選的指標、資源類型與篩選條件一樣
- 記憶體圖表請在 Console 用「新增小工具」加上去，指標選小 Lab 1 看到的 `guest` 記憶體指標

## 步驟 2：建立資訊主頁

對應講義：「建立自訂資訊主頁」→ 新增小工具 →「儲存」。

```bash
gcloud monitoring dashboards create --config-from-file=/tmp/quiz-helper-dashboard.json
```

**你應該會看到**：印出新資訊主頁的內容。到 Console「Monitoring → 資訊主頁」打開「考題小幫手」，看得到三個圖表。
