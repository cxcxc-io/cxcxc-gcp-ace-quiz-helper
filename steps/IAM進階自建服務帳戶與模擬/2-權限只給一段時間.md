# 2. 權限只給一段時間

> 對應講義：IAM 進階 → Lab 實作 →「權限只給一段時間」

## 步驟 1：設定督導帳號與專案結束時間

講義沒有對應的 Console 動作：先存成變數，下面的指令就不用改。

```bash
export SUPERVISOR=<督導的 Google 帳號 email>
export END_TIME=2027-01-31T16:00:00Z
```

- `END_TIME`：條件裡的時間一律用 UTC。台灣時間比 UTC 快 8 小時，所以 `2027-01-31T16:00:00Z` 就是台灣時間 2027 年 2 月 1 日 0 點。換成你想要的日期即可

## 步驟 2：試著幫 Viewer 加上條件

對應講義：在「檢視者」下方找「新增 IAM 條件」，加不上去。

```bash
gcloud projects add-iam-policy-binding ${PROJECT_ID} \
  --member="user:${SUPERVISOR}" \
  --role="roles/viewer" \
  --condition="expression=request.time < timestamp('${END_TIME}'),title=短期專案結束"
```

- `--condition="expression=...,title=..."`：條件由一段 CEL 運算式和標題組成
- `request.time < timestamp('...')`：請求的時間早於這個時間點才有效，也就是「到期時間」

**你應該會看到**：錯誤訊息，說明基本角色不能加條件（講義 IAM 章第 8 節陷阱）。

## 步驟 3：拿掉 Viewer

對應講義：刪除「檢視者」。

```bash
gcloud projects remove-iam-policy-binding ${PROJECT_ID} \
  --member="user:${SUPERVISOR}" \
  --role="roles/viewer" \
  --condition=None --format=none
```

- `--condition=None`：移除的是「沒有條件」的那一筆授權

## 步驟 4：改給三個檢視者角色，各加上到期條件

對應講義：加入 Compute 檢視者、記錄檢視者、Monitoring 檢視者，每個都「新增 IAM 條件」。

```bash
for ROLE in roles/compute.viewer roles/logging.viewer roles/monitoring.viewer; do
  gcloud projects add-iam-policy-binding ${PROJECT_ID} \
    --member="user:${SUPERVISOR}" \
    --role="${ROLE}" \
    --condition="expression=request.time < timestamp('${END_TIME}'),title=短期專案結束" \
    --format=none
done
```

- `for ROLE in ...; do ... done`：同一段指令對三個角色各跑一次
- 這三個都是預先定義角色，可以加條件

**你應該會看到**：三次 `Updated IAM policy for project [...]`。

## 步驟 5：確認條件已經掛上

對應講義：三個角色旁邊都有條件標示。

```bash
gcloud projects get-iam-policy ${PROJECT_ID} \
  --flatten="bindings[].members" \
  --filter="bindings.members:user:${SUPERVISOR}" \
  --format="table(bindings.role, bindings.condition.title, bindings.condition.expression)"
```

**你應該會看到**：三列，每一列的條件標題都是「短期專案結束」，運算式裡有你設的時間。
