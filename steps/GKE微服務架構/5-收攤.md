# 5. 收攤

> 對應講義：微服務架構：Google Kubernetes Engine → Lab 實作 →「收攤」
>
> 叢集和負載平衡器開著就會計費，這一章做完就刪。`quiz-helper:v1.1` 映像檔、服務帳戶、值區與 Firestore 題庫，Cloud Run 章還會用到，**先不要刪**。

## 開始前：確認 Cloud Shell 在你的專案

講義沒有對應的 Console 動作。Cloud Shell 不一定停在這門課的專案（重開 Cloud Shell、從別的專案頁面打開、或之前切換過專案都可能），所以每一份都先執行這一段，順便把這一份要用的變數設好。

```bash
gcloud config set project "你的專案ID"
export PROJECT_ID=$(gcloud config get-value project)
export REGION=asia-east1
echo "目前專案：${PROJECT_ID}"
```

- `"你的專案ID"`：換成你的專案 ID（Console 上方的專案選單看得到），雙引號保留

**你應該會看到**：`Updated property [core/project].`，接著印出你的專案 ID。出現 `WARNING: You do not appear to have access to project` 代表專案 ID 打錯了。

## 步驟 1：先刪 Service，再刪叢集

對應講義：「Gateway、Service 與 Ingress」刪除 quiz-helper，再到「叢集」刪除 quiz-helper-cluster。

```bash
kubectl delete service quiz-helper
gcloud container clusters delete quiz-helper-cluster --region=${REGION} --quiet
```

- 先刪 Service：讓 GKE 把它建立的負載平衡器一起刪掉，不留下會計費的轉送規則
- `--quiet`：不再詢問確認
- 刪除叢集約需 5 分鐘

**你應該會看到**：`service "quiz-helper" deleted`，接著 `Deleted [.../clusters/quiz-helper-cluster].`

## 步驟 2：確認沒有留下東西

對應講義：「叢集」清單是空的；「網路服務」→「負載平衡」沒有小幫手的負載平衡器。

```bash
gcloud container clusters list
gcloud compute forwarding-rules list
```

**你應該會看到**：兩個指令都是 `Listed 0 items.`（專案裡有其他資源的話，確認沒有 `quiz-helper` 相關的項目即可）。

> 授予節點服務帳戶與 Kubernetes 服務帳戶的角色不會計費，可以先留著；課程全部結束時的清理指令見 `labs/lab-2.md` 最後的「課程全部結束時」。
