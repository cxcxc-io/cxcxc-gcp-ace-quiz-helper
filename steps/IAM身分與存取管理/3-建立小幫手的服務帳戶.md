# 3. 建立小幫手的服務帳戶

> 對應講義：IAM 身分與存取管理 → Lab 實作 →「建立小幫手的服務帳戶」

## 步驟 1：建立服務帳戶

對應講義：「IAM 與管理 → 服務帳戶 → 建立服務帳戶」，名稱填 quiz-helper、說明填「考題小幫手」。

```bash
gcloud iam service-accounts create quiz-helper \
  --display-name="quiz-helper" \
  --description="考題小幫手"
```

- `quiz-helper`：服務帳戶 ID，會成為 email 的前半段
- `--display-name`：Console 上顯示的名稱
- `--description`：說明，讓別人知道這個服務帳戶的用途

**你應該會看到**：`Created service account [quiz-helper].`

## 步驟 2：把服務帳戶的 email 存成變數

講義沒有對應的 Console 動作：之後授權、部署都要用到這個 email。

```bash
export SA_EMAIL=quiz-helper@${PROJECT_ID}.iam.gserviceaccount.com
echo ${SA_EMAIL}
```

- 服務帳戶的 email 格式固定是「ID@專案 ID.iam.gserviceaccount.com」（講義第 7 節）

**你應該會看到**：`quiz-helper@<你的專案 ID>.iam.gserviceaccount.com`

> Cloud Shell 斷線後變數會消失，之後的章節用到 `SA_EMAIL` 前，記得再執行一次這行 `export`。

## 步驟 3：確認服務帳戶已建立

對應講義：服務帳戶清單出現 quiz-helper。

```bash
gcloud iam service-accounts list --filter="email:${SA_EMAIL}"
```

- `gcloud iam service-accounts list`：列出專案裡的服務帳戶
- `--filter="email:..."`：只顯示這一個

**你應該會看到**：一列 `quiz-helper@<你的專案 ID>.iam.gserviceaccount.com`，`DISABLED` 欄位是 `False`。
