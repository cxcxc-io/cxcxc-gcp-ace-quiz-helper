# 3. 題庫能不能被別人看到

> 對應講義：Cloud Storage 物件儲存 → Lab 實作 →「題庫能不能被別人看到」

講義用瀏覽器驗證了三件事：自己看得到、匿名看不到、想公開也公開不了。指令版用 `curl` 直接對 Cloud Storage 發出請求，可以更清楚看到「有沒有帶身分」的差別。

## 步驟 1：不帶身分，直接讀取題庫

對應講義：把網址貼到無痕視窗，沒登入就看不到。

```bash
curl -s -o /dev/null -w "%{http_code}\n" \
  https://storage.googleapis.com/${BUCKET}/questions.csv
```

- `curl`：直接對網址發出 HTTP 請求，這裡**沒有帶任何身分**，等於匿名存取
- `-o /dev/null`：不印出內容
- `-w "%{http_code}\n"`：只印出 HTTP 狀態碼

**你應該會看到**：`403`，代表拒絕存取。知道網址也沒用。

## 步驟 2：帶上你的身分，再讀一次

對應講義：點「已驗證網址」，用你登入的帳號存取。

```bash
curl -s -o /dev/null -w "%{http_code}\n" \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  https://storage.googleapis.com/${BUCKET}/questions.csv
```

- `gcloud auth print-access-token`：取得你目前登入帳號的短期存取權杖
- `-H "Authorization: Bearer ..."`：把權杖放進請求的標頭，告訴 Cloud Storage「我是誰」

**你應該會看到**：`200`，代表成功。同一個網址，差別只在有沒有帶身分。

## 步驟 3：試著把題庫公開給所有人

對應講義：「權限」分頁 → 授予 allUsers「Storage 物件檢視者」，被拒絕。

```bash
gcloud storage buckets add-iam-policy-binding gs://${BUCKET} \
  --member=allUsers \
  --role=roles/storage.objectViewer
```

- `--member=allUsers`：代表「網路上的任何人」，不需要登入
- `roles/storage.objectViewer`：可以讀取物件

**你應該會看到**：錯誤訊息，狀態碼 `412`，說明值區強制禁止公開存取。這就是建立值區時 `--public-access-prevention` 的效果。

> 這三步就是零信任的意思：不看你從哪裡來、知不知道網址，每一次存取都要確認身分與權限；就算有人想開放，政策也會擋下來。
