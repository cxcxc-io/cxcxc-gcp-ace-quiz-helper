# 2. 上傳題庫

> 對應講義：Cloud Storage 物件儲存 → Lab 實作 →「上傳題庫」
>
> 這一份用到上一份的變數 `BUCKET`。Cloud Shell 斷線過的話，先重新執行 [1-建立小幫手的值區](1-建立小幫手的值區.md) 的步驟 1。

講義用 Console 上傳時，要先把檔案下載到電腦。指令版不用：題庫已經跟著程式碼下載到 Cloud Shell 裡了。

## 步驟 1：進到程式碼的資料夾

講義沒有對應的 Console 動作：範例題庫在程式碼的 `data/` 資料夾裡。

```bash
cd ~/cloudshell_open/cxcxc-gcp-ace-quiz-helper
ls data/
```

**你應該會看到**：`questions.csv`

## 步驟 2：上傳到值區

對應講義：「物件」分頁 →「上傳」→「上傳檔案」。

```bash
gcloud storage cp data/questions.csv gs://${BUCKET}/
```

- `gcloud storage cp 來源 目的地`：複製檔案。目的地是 `gs://` 開頭就是上傳到值區
- 目的地結尾的 `/`：代表放進值區的最上層，檔名維持 `questions.csv`

**你應該會看到**：`Copying file://data/questions.csv to gs://.../questions.csv`，最後顯示已完成。

## 步驟 3：確認檔案在值區裡

對應講義：物件清單出現 questions.csv。

```bash
gcloud storage ls -l gs://${BUCKET}/
```

- `gcloud storage ls`：列出值區裡的物件
- `-l`：多顯示大小與建立時間

**你應該會看到**：一列 `gs://<你的專案 ID>-gcp-ace-cxcxc/questions.csv`，前面是檔案大小與時間。

> 講義已經用 Console 上傳過的話，這裡會覆蓋同名的檔案，內容一樣，不影響後面的步驟。
