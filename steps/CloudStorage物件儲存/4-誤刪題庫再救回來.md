# 4. 誤刪題庫，再救回來

> 對應講義：Cloud Storage 物件儲存 → Lab 實作 →「誤刪題庫，再救回來」

## 步驟 1：開啟物件版本管理

對應講義：「保護」分頁 →「物件版本管理」改成開啟。

```bash
gcloud storage buckets update gs://${BUCKET} --versioning
```

- `--versioning`：開啟版本管理。之後刪除或覆蓋的物件，都會留下一個「非目前版本」

**你應該會看到**：`Updating gs://.../...` 並完成。

## 步驟 2：刪除題庫

對應講義：勾選 questions.csv →「刪除」。

```bash
gcloud storage rm gs://${BUCKET}/questions.csv
gcloud storage ls gs://${BUCKET}/
```

- `gcloud storage rm`：刪除物件
- 第二行再列一次值區

**你應該會看到**：`Removing gs://.../questions.csv...`；第二行沒有列出任何物件，值區看起來是空的。

## 步驟 3：列出所有版本

對應講義：打開「顯示已刪除的資料」（或「顯示非目前版本」）。

```bash
gcloud storage ls -a gs://${BUCKET}/
```

- `-a`：連同非目前版本一起列出

**你應該會看到**：`gs://.../questions.csv#1234567890123456`。`#` 後面那串數字是這個版本的**世代編號（generation）**，每一個版本都有自己的編號。

## 步驟 4：把舊版本還原成目前版本

對應講義：「版本記錄」分頁 → 選剛才的版本 →「還原」。

```bash
export GEN=$(gcloud storage ls -a gs://${BUCKET}/questions.csv | tail -1 | sed 's/.*#//')
echo ${GEN}
gcloud storage cp gs://${BUCKET}/questions.csv#${GEN} gs://${BUCKET}/questions.csv
```

- 第一行：從上一步的清單取出最後一個版本的世代編號，存成變數 `GEN`
- `gcloud storage cp 舊版本 目前名稱`：把舊版本複製一份成為目前版本，這就是「還原」

**你應該會看到**：`Copying gs://.../questions.csv#... to gs://.../questions.csv`

## 步驟 5：確認題庫回來了

對應講義：物件清單恢復顯示 questions.csv。

```bash
gcloud storage ls gs://${BUCKET}/
```

**你應該會看到**：`gs://<你的專案 ID>-gcp-ace-cxcxc/questions.csv`

> 再執行一次 `gcloud storage ls -a gs://${BUCKET}/`，會看到兩個版本：被刪掉的舊版本，和剛還原的目前版本。下一份就是要處理這些越積越多的舊版本。
