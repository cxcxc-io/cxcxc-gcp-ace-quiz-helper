# 1. 建立小幫手的值區

> 對應講義：Cloud Storage 物件儲存 → Lab 實作 →「建立小幫手的值區」
>
> 這一份用到「組織帳號設計」設好的變數 `PROJECT_ID`、`REGION`。Cloud Shell 斷線過的話，先執行 [組織帳號設計/1-確認專案與帳單帳戶](../組織帳號設計/1-確認專案與帳單帳戶.md) 的步驟 2、3。

講義裡建立值區時，你依序走過名稱、位置、儲存空間級別、存取權控管四頁。指令版是同一行指令的四個參數。

## 步驟 1：把值區名稱存成變數

對應講義：「名稱」填 `<你的專案 ID>-gcp-ace-cxcxc`。

```bash
export BUCKET=${PROJECT_ID}-gcp-ace-cxcxc
echo ${BUCKET}
```

- 小幫手就是用「專案 ID ＋ `-gcp-ace-cxcxc`」這個規則找值區，所以名稱要完全一樣

**你應該會看到**：`<你的專案 ID>-gcp-ace-cxcxc`

## 步驟 2：建立值區

對應講義：四頁的選項全部填完，按「建立」。

```bash
gcloud storage buckets create gs://${BUCKET} \
  --location=${REGION} \
  --default-storage-class=STANDARD \
  --uniform-bucket-level-access \
  --public-access-prevention
```

每個參數對應講義的哪一頁：

- `gs://${BUCKET}`：「名稱」頁。指令裡的值區一律寫成 `gs://` 開頭
- `--location=${REGION}`：「資料儲存位置」頁。給單一區域名稱（`asia-east1`）就是「區域」位置類型（講義第 5 節）
- `--default-storage-class=STANDARD`：「儲存空間級別」頁（講義第 6 節）
- `--uniform-bucket-level-access`：「控管物件存取權」頁的「統一」（講義第 10 節）
- `--public-access-prevention`：「控管物件存取權」頁的「強制禁止公開存取」（講義第 10 節）

**你應該會看到**：`Creating gs://<你的專案 ID>-gcp-ace-cxcxc/...`

> 出現 `409`、名稱已被使用：值區名稱全球唯一。用專案 ID 開頭幾乎不會撞名，通常是你已經建過了，直接做下一步確認即可。

## 步驟 3：確認設定

對應講義：值區清單看到位置 asia-east1、預設儲存空間級別 Standard。

```bash
gcloud storage buckets describe gs://${BUCKET} \
  --format="yaml(name,location,default_storage_class,uniform_bucket_level_access,public_access_prevention)"
```

- `--format="yaml(...)"`：只列出這幾個跟小幫手有關的設定

**你應該會看到**：

```
default_storage_class: STANDARD
location: ASIA-EAST1
name: <你的專案 ID>-gcp-ace-cxcxc
public_access_prevention: enforced
uniform_bucket_level_access: true
```
