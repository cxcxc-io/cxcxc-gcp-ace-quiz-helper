# 5. 讓舊版本自動清掉

> 對應講義：Cloud Storage 物件儲存 → Lab 實作 →「讓舊版本自動清掉」

講義在 Console 的「生命週期」分頁依序選了動作和條件。指令版要把同樣的規則寫成一個 JSON 檔，再套用到值區上。

## 步驟 1：寫出生命週期規則

對應講義：動作選「刪除物件」，條件勾選「成為非目前版本後的天數」填 7。

```bash
cat > /tmp/lifecycle.json <<'JSON'
{
  "rule": [
    {
      "action": {"type": "Delete"},
      "condition": {"daysSinceNoncurrentTime": 7}
    }
  ]
}
JSON
cat /tmp/lifecycle.json
```

- `cat > 檔案 <<'JSON' ... JSON`：把中間的內容寫進 `/tmp/lifecycle.json`
- `"action": {"type": "Delete"}`：講義的「刪除物件」
- `"daysSinceNoncurrentTime": 7`：講義的「成為非目前版本後的天數：7」。目前版本不受影響

**你應該會看到**：印出剛寫好的 JSON。

## 步驟 2：套用到值區

對應講義：按「建立」。

```bash
gcloud storage buckets update gs://${BUCKET} --lifecycle-file=/tmp/lifecycle.json
```

- `--lifecycle-file`：用檔案裡的規則**取代**值區現有的生命週期設定

**你應該會看到**：`Updating gs://.../...` 並完成。

## 步驟 3：確認規則已生效

對應講義：生命週期規則清單出現一條規則。

```bash
gcloud storage buckets describe gs://${BUCKET} --format="yaml(lifecycle_config)"
```

**你應該會看到**：

```
lifecycle_config:
  rule:
  - action:
      type: Delete
    condition:
      daysSinceNoncurrentTime: 7
```

> 講義已經在 Console 建過同一條規則的話，這裡會用相同內容覆蓋，結果一樣只有一條規則。
