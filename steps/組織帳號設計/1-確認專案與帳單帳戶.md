# 1. 確認專案與帳單帳戶

> 對應講義：組織帳號設計 → Lab 實作 →「確認專案與帳單帳戶」
>
> 指令要在 Cloud Shell 執行。還沒開過 Cloud Shell 的話，先做 [2-打開CloudShell並取得程式碼](2-打開CloudShell並取得程式碼.md)，再回來。

講義裡你在 Console 做了三件事：用專案選擇器找到專案、記下專案 ID、到「帳單」確認有沒有綁帳單帳戶。這裡用指令把同樣三件事再做一次。

## 步驟 1：列出你能用的專案

對應講義：點專案選擇器，看到專案清單。

```bash
gcloud projects list
```

**你應該會看到**：一張表，每一列是一個專案。

```
PROJECT_ID            NAME          PROJECT_NUMBER
cxcxc-ace-0123        ACE 上課專案    123456789012
```

- `PROJECT_ID`：就是講義要你記下的「ID」那一欄，之後所有指令都用它
- `NAME`：選擇器上顯示的名稱，指令用不到
- `PROJECT_NUMBER`：系統給的編號，後面的章節會用到（回顧講義第 5 節：三種專案識別碼）

## 步驟 2：切換到上課用的專案

對應講義：在選擇器裡點專案名稱，切換過去。

```bash
gcloud config set project <你的專案 ID>
```

把 `<你的專案 ID>` 換成上一步 `PROJECT_ID` 欄位的值。這是整個 Lab 唯一要你自己改的地方。

- `gcloud config set project`：設定 gcloud 的「目前專案」。之後的指令沒有特別指定專案時，都會作用在這個專案

**你應該會看到**：`Updated property [core/project].`，終端機提示字元結尾的括號也會變成這個專案 ID。

## 步驟 3：把專案 ID 和區域存成變數

講義沒有對應的 Console 動作：這一步是為了讓後面的指令可以直接複製貼上。

```bash
export PROJECT_ID=$(gcloud config get-value project)
export REGION=asia-east1
echo "專案：${PROJECT_ID}，區域：${REGION}"
```

- `gcloud config get-value project`：讀出剛才設定的專案 ID
- `export PROJECT_ID=...`：存進變數 `PROJECT_ID`，之後寫 `${PROJECT_ID}` 就等於專案 ID
- `REGION=asia-east1`：台灣區域，本課程的資源都放這裡

**你應該會看到**：`專案：<你的專案 ID>，區域：asia-east1`

> Cloud Shell 閒置一段時間會斷線，重新連上後變數會消失，再執行一次這兩行 `export` 即可。

## 步驟 4：確認專案綁了帳單帳戶

對應講義：「≡」導覽選單 →「帳單」，看有沒有帳單帳戶名稱。

```bash
gcloud billing projects describe ${PROJECT_ID}
```

- `gcloud billing projects describe`：顯示這個專案的帳單資訊

**你應該會看到**：

```
billingAccountName: billingAccounts/XXXXXX-XXXXXX-XXXXXX
billingEnabled: true
name: projects/<你的專案 ID>/billingInfo
projectId: <你的專案 ID>
```

- `billingEnabled: true`：已經綁好，可以往下做
- `billingEnabled: false`：還沒綁，回講義照 Console 步驟「連結帳單帳戶」
- `billingAccountName`：綁定的帳單帳戶 ID，下一個小 Lab 設定預算時會用到
