# 3. 設定預算警示

> 對應講義：組織帳號設計 → Lab 實作 →「設定預算警示」

**需要的角色**：帳單帳戶上的帳單帳戶管理員（Billing Account Administrator）或帳單帳戶費用管理員（Billing Account Costs Manager）。

講義裡你在「帳單 → 預算與快訊 → 建立預算」依序填了範圍、金額、動作三頁。用指令建立時，這三頁的內容會變成同一行指令的參數。

> 這一份延續 [1-確認專案與帳單帳戶](1-確認專案與帳單帳戶.md) 設好的變數 `PROJECT_ID`。Cloud Shell 斷線過的話，先重新執行那裡的步驟 3。

## 步驟 1：取得帳單帳戶 ID

講義沒有對應的 Console 動作：在 Console 建預算時，你本來就在帳單帳戶的頁面裡；用指令就要明確說出是哪一個帳單帳戶。

```bash
export BILLING_ACCOUNT=$(gcloud billing projects describe ${PROJECT_ID} \
  --format="value(billingAccountName)" | sed 's|billingAccounts/||')
echo ${BILLING_ACCOUNT}
```

- `gcloud billing projects describe`：上一份步驟 4 看過的指令，會印出 `billingAccountName: billingAccounts/XXXXXX-...`
- `--format="value(billingAccountName)"`：只取出這一個欄位的值
- `sed 's|billingAccounts/||'`：把前面的 `billingAccounts/` 去掉，只留下 ID
- `export BILLING_ACCOUNT=...`：存成變數，下一步用

**你應該會看到**：一串 `XXXXXX-XXXXXX-XXXXXX` 格式的帳單帳戶 ID。

## 步驟 2：設定預算金額

對應講義：「金額」那一頁，預算類型選「指定金額」，填 300。

```bash
export BUDGET_AMOUNT=300TWD
```

- 金額後面直接接幣別。**幣別要和帳單帳戶相同**，例如台幣帳戶用 `300TWD`、美元帳戶用 `10USD`，不同會出錯

## 步驟 3：建立預算

對應講義：三頁全部填完，按「完成」。

```bash
gcloud billing budgets create \
  --billing-account=${BILLING_ACCOUNT} \
  --display-name="quiz-helper 預算" \
  --budget-amount=${BUDGET_AMOUNT} \
  --filter-projects=projects/${PROJECT_ID} \
  --threshold-rule=percent=0.5 \
  --threshold-rule=percent=0.9 \
  --threshold-rule=percent=1.0
```

每個參數對應講義的哪一頁：

- `--billing-account`：預算建在**帳單帳戶**上，不是建在專案上（回顧講義第 6 節）
- `--display-name`：「範圍」頁的名稱
- `--filter-projects`：「範圍」頁只勾上課用的專案。不加這個參數，會計算整個帳單帳戶的花費
- `--budget-amount`：「金額」頁填的金額
- `--threshold-rule=percent=0.5`：「動作」頁的 50% 門檻，下面兩行是 90% 和 100%

**你應該會看到**：印出剛建立的預算內容，包含 `displayName: quiz-helper 預算`。

> 出現 `PERMISSION_DENIED`：代表你在帳單帳戶上沒有上面的角色，請帳單帳戶管理員授權，或請他代為建立。

## 步驟 4：確認預算已建立

對應講義：預算清單出現 quiz-helper 預算。

```bash
gcloud billing budgets list --billing-account=${BILLING_ACCOUNT}
```

- `gcloud billing budgets list`：列出這個帳單帳戶底下的所有預算

**你應該會看到**：清單中有 `displayName: quiz-helper 預算`，金額是你填的數字。

> 講義用 Console 已經建過一個預算的話，這裡會看到兩個同名的預算。到 Console 的預算清單刪掉其中一個即可。
