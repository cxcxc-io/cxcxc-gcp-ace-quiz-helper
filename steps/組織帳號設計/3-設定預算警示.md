# 3. 設定預算警示

> 對應講義：組織帳號設計 → Lab 實作 →「設定預算警示」

## 這一段做什麼

設定預算，花費到 50%、90%、100% 時寄信通知。**預算只會通知，不會自動停止服務。**

需要的角色：帳單帳戶上的**帳單帳戶管理員（Billing Account Administrator）**或**帳單帳戶費用管理員（Billing Account Costs Manager）**。

## 指令

```bash
# 取得這個專案綁定的帳單帳戶 ID
export BILLING_ACCOUNT=$(gcloud billing projects describe ${PROJECT_ID} \
  --format="value(billingAccountName)" | sed 's|billingAccounts/||')
echo ${BILLING_ACCOUNT}

# 金額的幣別要和帳單帳戶相同，例如 300TWD 或 10USD
export BUDGET_AMOUNT=300TWD

gcloud billing budgets create \
  --billing-account=${BILLING_ACCOUNT} \
  --display-name="quiz-helper 預算" \
  --budget-amount=${BUDGET_AMOUNT} \
  --filter-projects=projects/${PROJECT_ID} \
  --threshold-rule=percent=0.5 \
  --threshold-rule=percent=0.9 \
  --threshold-rule=percent=1.0

# 確認預算已建立
gcloud billing budgets list --billing-account=${BILLING_ACCOUNT}
```

## 每個參數在做什麼

| 指令或參數 | 說明 |
| --- | --- |
| `--format="value(billingAccountName)"` | 只取出帳單帳戶欄位，結果像 `billingAccounts/XXXXXX-...` |
| `sed 's|billingAccounts/||'` | 去掉前綴，只留帳單帳戶 ID |
| `gcloud billing budgets create` | 預算是建在**帳單帳戶**上，不是建在專案上 |
| `--display-name` | 預算名稱，會出現在 Console 的預算清單 |
| `--budget-amount` | 金額加幣別；幣別要和帳單帳戶一樣，否則會出錯 |
| `--filter-projects` | 只計算這個專案的花費；不加就會計算整個帳單帳戶 |
| `--threshold-rule=percent=0.5` | 花到 50% 時通知，另外兩行是 90% 和 100% |

## 預期看到的結果

`list` 的結果中有 `displayName: quiz-helper 預算`，金額為你填的數字。

> 出現 `PERMISSION_DENIED`：代表你在帳單帳戶上沒有上面的角色，請帳單帳戶管理員授權，或請他代為建立。
