# 1. 切到下一版的程式碼

> 對應講義：DevSecOps 架構：軟體供應鏈 → Lab 實作 →「切到下一版的程式碼」
>
> 這一章從這一份開始，**不要再執行** [ComputeEngine虛擬機器/0-開始前](../ComputeEngine虛擬機器/0-開始前.md) 的步驟 1，否則程式碼會切回 `lab-1`。變數改用這一份的步驟 3 設定。

## 步驟 1：看看兩個版本差在哪

對應講義：在 GitHub 切換標記，比較 `lab-1` 與 `lab-2` 的 Dockerfile。

```bash
cd ~/cloudshell_open/cxcxc-gcp-ace-quiz-helper
git fetch --tags --force
git describe --tags
git log --oneline lab-1..lab-2
git diff lab-1 lab-2 -- Dockerfile
```

- `git fetch --tags --force`：把 GitHub 上最新的標記抓下來
- `git describe --tags`：目前的程式碼是哪一個標記
- `git log --oneline lab-1..lab-2`：從 `lab-1` 到 `lab-2` 之間做過哪些修改，一筆一行
- `git diff lab-1 lab-2 -- Dockerfile`：只比較 Dockerfile 這個檔案

**你應該會看到**：

- `git describe --tags` 印出 `lab-1`（Compute Engine 章切過去的版本）
- `git log` 列出幾筆修改，開頭是 `v1.1：` 的就是這次新增的功能
- `git diff` 裡有一行 `-ARG APP_VERSION=v1`、一行 `+ARG APP_VERSION=v1.1`

## 步驟 2：切到 lab-2

對應講義：在 Cloud Shell 切到 lab-2（只有指令）。

```bash
git checkout lab-2
git describe --tags
ls deploy/
```

- `git checkout lab-2`：把資料夾裡的程式碼換成 `lab-2` 這個版本
- `ls deploy/`：確認多了 GKE 章要用的部署檔

**你應該會看到**：`git describe --tags` 印出 `lab-2`；`deploy/` 底下有 `gke` 與 `vm` 兩個資料夾。

### 常見卡關：出現「Your local changes ... would be overwritten」

代表你在資料夾裡改過某些檔案。先把修改暫存起來再切換：

```bash
git stash
git checkout lab-2
```

- `git stash`：把還沒提交的修改先收起來，之後要找回來可以用 `git stash pop`

## 步驟 3：設定這一章會用到的變數

講義沒有對應的 Console 動作。

```bash
gcloud config set project <你的專案 ID>
export PROJECT_ID=$(gcloud config get-value project)
export REGION=asia-east1
export ZONE=asia-east1-b
export IMAGE_V11=${REGION}-docker.pkg.dev/${PROJECT_ID}/quiz-helper/quiz-helper:v1.1
echo "${PROJECT_ID} ${IMAGE_V11}"
```

- `IMAGE_V11`：等一下要打包的映像檔，跟 Compute Engine 章的 v1 放在同一個存放區，只有標記不同

**你應該會看到**：印出專案 ID 與結尾是 `quiz-helper:v1.1` 的映像檔名稱。

> Cloud Shell 斷線重連後，重新執行這一步即可（程式碼會停在 `lab-2`，不用重新切換）。

## 步驟 4：確認 VM 上的小幫手沒有受影響

對應講義：用手機重新整理小幫手，版本還是 v1。

```bash
export VM_IP=$(gcloud compute instances describe quiz-helper-vm --zone=${ZONE} \
  --format="value(networkInterfaces[0].accessConfigs[0].natIP)")
curl -s http://${VM_IP}/healthz
```

**你應該會看到**：`{"status":"ok","version":"v1"}`。VM 跑的是成品倉裡的 `quiz-helper:v1`，Cloud Shell 裡切換程式碼不會影響它。
