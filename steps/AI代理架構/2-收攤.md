# 2. 收攤

> 對應講義：AI 代理架構 → Lab 實作 →「收攤」
>
> Dify 的 VM 開著就會計費，下課就刪。VM 刪掉之後，Dify 裡建立的應用程式、知識庫與帳號都會一起消失；想保留的話，先在 Dify 裡把應用程式匯出成 DSL 檔。

## 開始前：確認 Cloud Shell 在你的專案

講義沒有對應的 Console 動作。Cloud Shell 不一定停在這門課的專案（重開 Cloud Shell、從別的專案頁面打開、或之前切換過專案都可能），所以每一份都先執行這一段，順便把這一份要用的變數設好。

```bash
gcloud config set project "你的專案ID"
export PROJECT_ID=$(gcloud config get-value project)
export ZONE=asia-east1-b
echo "目前專案：${PROJECT_ID}"
```

- `"你的專案ID"`：換成你的專案 ID（Console 上方的專案選單看得到），雙引號保留

**你應該會看到**：`Updated property [core/project].`，接著印出你的專案 ID。

## 步驟 1：刪除 VM 與防火牆規則

對應講義：VM 執行個體勾選 dify-lab →「刪除」；防火牆勾選 allow-dify-http →「刪除」。

```bash
gcloud compute instances delete dify-lab --zone=${ZONE} --quiet
gcloud compute firewall-rules delete allow-dify-http --quiet
```

- `--quiet`：不再詢問確認；開機磁碟預設會跟著 VM 一起刪除

**你應該會看到**：`Deleted [.../instances/dify-lab].` 與 `Deleted [.../firewalls/allow-dify-http].`

## 步驟 2：確認收乾淨

```bash
gcloud compute instances list --filter="name=dify-lab"
gcloud compute firewall-rules list --filter="name=allow-dify-http"
```

**你應該會看到**：兩個指令都是 `Listed 0 items.`
