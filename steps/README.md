# 逐步指令（對照講義）

這個資料夾放的是**講義各章「Lab 實作」的指令版**，依章節分資料夾、依小節分檔案。

- **講義**：教你在 Console 怎麼找到按鍵、一步一步點，並說明每一步在做什麼。
- **這個資料夾**：同一件事用 gcloud 指令怎麼做，每個參數都有說明。建議先在 Console 點過一次，再回來看指令。
- **`labs/` 資料夾**：一個 Lab 一份完整說明，適合趕進度、一次做完拿到成果。
