# 3. 答錯次數做成紀錄型指標

> 對應講義：Cloud Logging → Lab 實作 →「答錯次數做成紀錄型指標」

## 步驟 1：先確認篩選條件查得到資料

對應講義：在記錄檔探索工具貼上作答紀錄且 correct 是 false 的查詢。先用手機故意答錯一兩題。

```bash
gcloud logging read \
  'resource.type="gce_instance" AND jsonPayload.event="answer" AND jsonPayload.correct=false' \
  --freshness=1h --limit=3 \
  --format="table(timestamp, jsonPayload.nickname, jsonPayload.question_id)"
```

- `jsonPayload.correct=false`：布林值不加引號

**你應該會看到**：幾筆答錯的紀錄。

## 步驟 2：建立紀錄型指標

對應講義：「動作」→「建立指標」，計數器、名稱 quiz_helper_wrong_answers。

```bash
gcloud logging metrics create quiz_helper_wrong_answers \
  --description="小幫手答錯次數" \
  --log-filter='resource.type="gce_instance" AND jsonPayload.event="answer" AND jsonPayload.correct=false'
```

- 沒有特別指定時，紀錄型指標就是**計數器**：每有一筆符合的紀錄就加 1
- 指標在 Cloud Monitoring 的名稱是 `logging.googleapis.com/user/quiz_helper_wrong_answers`

**你應該會看到**：`Created [quiz_helper_wrong_answers].`

## 步驟 3：確認指標存在

```bash
gcloud logging metrics describe quiz_helper_wrong_answers
```

**你應該會看到**：`filter` 就是剛才的查詢條件。接著用手機再答錯幾題，兩三分鐘後到 Console 的 Metrics Explorer 搜尋 `quiz_helper_wrong_answers` 看圖。
