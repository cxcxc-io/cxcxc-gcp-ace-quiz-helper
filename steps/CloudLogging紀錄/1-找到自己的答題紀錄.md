# 1. 找到自己的答題紀錄

> 對應講義：Cloud Logging → Lab 實作 →「找到自己的答題紀錄」
>
> 先完成 [ComputeEngine虛擬機器/0-開始前](../ComputeEngine虛擬機器/0-開始前.md)，設定 `PROJECT_ID`、`ZONE`、`BUCKET` 等變數。

## 開始前：確認 Cloud Shell 在你的專案

講義沒有對應的 Console 動作。Cloud Shell 不一定停在這門課的專案（重開 Cloud Shell、從別的專案頁面打開、或之前切換過專案都可能），所以每一份都先執行這一段，順便把這一份要用的變數設好。

```bash
gcloud config set project "你的專案ID"
export PROJECT_ID=$(gcloud config get-value project)
echo "目前專案：${PROJECT_ID}"
```

- `"你的專案ID"`：換成你的專案 ID（Console 上方的專案選單看得到），雙引號保留

**你應該會看到**：`Updated property [core/project].`，接著印出你的專案 ID。出現 `WARNING: You do not appear to have access to project` 代表專案 ID 打錯了。

## 步驟 1：查自己的作答

對應講義：在記錄檔探索工具貼上三行查詢條件。

```bash
export NICKNAME="你答題時用的暱稱"
gcloud logging read \
  "resource.type=\"gce_instance\" AND jsonPayload.event=\"answer\" AND jsonPayload.nickname=\"${NICKNAME}\"" \
  --freshness=1h \
  --limit=5 \
  --format="table(timestamp, jsonPayload.question_id, jsonPayload.correct, jsonPayload.elapsed_ms)"
```

- 查詢條件跟記錄檔探索工具的寫法一樣，多個條件用 `AND` 串起來
- `resource.type="gce_instance"`：紀錄來自 Compute Engine VM
- `jsonPayload.event="answer"`：小幫手印出的 JSON 裡，`event` 欄位是 `answer` 的那幾筆
- `--freshness=1h`：只查過去 1 小時，對應講義的時間範圍
- `--format="table(...)"`：只列出幾個欄位，就像在記錄檔探索工具展開紀錄看 jsonPayload

**你應該會看到**：每答一題一列，`CORRECT` 是 `True` 或 `False`。

## 步驟 2：找匯入題庫的紀錄

對應講義：把 event 改成 import 再查一次。

```bash
gcloud logging read \
  'resource.type="gce_instance" AND jsonPayload.event="import"' \
  --freshness=7d \
  --limit=3 \
  --format="yaml(timestamp, jsonPayload)"
```

**你應該會看到**：Compute Engine 章匯入題庫時留下的紀錄，`jsonPayload` 裡有匯入的檔名與題數。
