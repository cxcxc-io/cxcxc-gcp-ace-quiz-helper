# 3. 查出是誰讀了題庫

> 對應講義：Cloud Logging → Lab 實作 →「查出是誰讀了題庫」
>
> 兩人一組：除了步驟 5，都由**管理員（你）**執行。

## 步驟 1：讀一次題庫

對應講義：在 Cloud Storage 下載 questions.csv。

```bash
gcloud storage cat gs://${BUCKET}/questions.csv | head -2
```

## 步驟 2：查資料存取紀錄

對應講義：照指令版查資料存取稽核紀錄，查不到。

```bash
gcloud logging read \
  'logName:"cloudaudit.googleapis.com%2Fdata_access" AND protoPayload.serviceName="storage.googleapis.com"' \
  --freshness=1h --limit=5 \
  --format="table(timestamp, protoPayload.methodName, protoPayload.authenticationInfo.principalEmail)"
```

- `cloudaudit.googleapis.com%2Fdata_access`：資料存取稽核紀錄

**你應該會看到**：什麼都沒有。Cloud Storage 的資料存取紀錄預設是關閉的（講義第 5 節）。

## 步驟 3：開啟 Cloud Storage 的資料讀取紀錄

對應講義：「IAM 與管理 → 稽核記錄」勾選 Google Cloud Storage 的「資料讀取」。

稽核紀錄的設定存在專案的允許政策裡（講義第 5 節「開啟的設定在 IAM 頁面」），指令版要把它讀出來、加上設定、再寫回去：

```bash
gcloud projects get-iam-policy ${PROJECT_ID} --format=json > /tmp/policy.json
python3 - <<'PY'
import json
p = json.load(open('/tmp/policy.json'))
p.setdefault('auditConfigs', [])
p['auditConfigs'] = [c for c in p['auditConfigs'] if c.get('service') != 'storage.googleapis.com']
p['auditConfigs'].append({'service': 'storage.googleapis.com',
                          'auditLogConfigs': [{'logType': 'DATA_READ'}]})
json.dump(p, open('/tmp/policy.json', 'w'), indent=2)
PY
gcloud projects set-iam-policy ${PROJECT_ID} /tmp/policy.json --format=none
```

- `get-iam-policy --format=json`：把整份允許政策存成檔案，裡面除了角色綁定，還有 `auditConfigs`
- 中間的 Python：在 `auditConfigs` 加上「Cloud Storage 要記錄 DATA_READ」
- `set-iam-policy`：把改好的整份政策寫回去。檔案裡帶著讀出時的 `etag`，如果這段時間有別人改過政策，寫回會失敗，避免蓋掉別人的修改

## 步驟 4：再讀一次，再查一次

對應講義：再下載一次 questions.csv，這次查得到。

```bash
sleep 60
gcloud storage cat gs://${BUCKET}/questions.csv | head -2
sleep 30
gcloud logging read \
  'logName:"cloudaudit.googleapis.com%2Fdata_access" AND protoPayload.serviceName="storage.googleapis.com"' \
  --freshness=10m --limit=5 \
  --format="table(timestamp, protoPayload.methodName, protoPayload.authenticationInfo.principalEmail)"
```

- 先等一分鐘，讓設定生效；讀完再等一下，讓紀錄寫進去

**你應該會看到**：`storage.objects.get`，最後一欄是你的帳號。

## 步驟 5：請同學用模擬身分讀一次

先由**管理員**重新授予同學模擬 quiz-helper 的權限（「IAM 進階」章的條件當天就到期了）：

```bash
export DEVELOPER=<同學的 Google 帳號 email>
export CLASS_END=<今天下課時間，UTC，例如 2026-10-27T10:00:00Z>
gcloud iam service-accounts add-iam-policy-binding ${SA_EMAIL} \
  --member="user:${DEVELOPER}" \
  --role="roles/iam.serviceAccountTokenCreator" \
  --condition="expression=request.time < timestamp('${CLASS_END}'),title=今天下課前" \
  --format=none
```

再由**同學**在自己的 Cloud Shell 執行：

```bash
export TARGET_PROJECT=<管理員的專案 ID>
gcloud storage ls gs://${TARGET_PROJECT}-gcp-ace-cxcxc/ \
  --impersonate-service-account=quiz-helper@${TARGET_PROJECT}.iam.gserviceaccount.com
```

## 步驟 6：看委派鏈

對應講義：找到同學那一筆，展開 serviceAccountDelegationInfo。

```bash
sleep 30
gcloud logging read \
  'logName:"cloudaudit.googleapis.com%2Fdata_access" AND protoPayload.methodName="storage.objects.list"' \
  --freshness=10m --limit=3 \
  --format="table(timestamp, protoPayload.authenticationInfo.principalEmail, protoPayload.authenticationInfo.serviceAccountDelegationInfo[0].firstPartyPrincipal.principalEmail)"
```

- `principalEmail`：表面上做這件事的身分，這裡是 quiz-helper
- `serviceAccountDelegationInfo[0].firstPartyPrincipal.principalEmail`：委派鏈的第一位，也就是真正發起模擬的人

**你應該會看到**：第二欄是 `quiz-helper@...`，第三欄是同學的帳號。

## 步驟 7：關掉資料讀取紀錄

對應講義：取消 Google Cloud Storage 的「資料讀取」。

```bash
gcloud projects get-iam-policy ${PROJECT_ID} --format=json > /tmp/policy.json
python3 - <<'PY'
import json
p = json.load(open('/tmp/policy.json'))
p['auditConfigs'] = [c for c in p.get('auditConfigs', []) if c.get('service') != 'storage.googleapis.com']
json.dump(p, open('/tmp/policy.json', 'w'), indent=2)
PY
gcloud projects set-iam-policy ${PROJECT_ID} /tmp/policy.json --format=none
```

- 資料存取紀錄量大、會計費，練習完就關掉
