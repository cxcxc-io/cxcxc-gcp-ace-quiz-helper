# 2. 建一條只給小幫手的規則

> 對應講義：VPC 網路 → Lab 實作 →「建一條只給小幫手的規則」

## 開始前：確認 Cloud Shell 在你的專案

講義沒有對應的 Console 動作。Cloud Shell 不一定停在這門課的專案（重開 Cloud Shell、從別的專案頁面打開、或之前切換過專案都可能），所以每一份都先執行這一段，順便把這一份要用的變數設好。

```bash
gcloud config set project "你的專案ID"
export PROJECT_ID=$(gcloud config get-value project)
export ZONE=asia-east1-b
export VM_IP=$(gcloud compute instances describe quiz-helper-vm --zone=${ZONE} \
  --format="value(networkInterfaces[0].accessConfigs[0].natIP)")
echo "目前專案：${PROJECT_ID}"
```

- `"你的專案ID"`：換成你的專案 ID（Console 上方的專案選單看得到），雙引號保留

**你應該會看到**：`Updated property [core/project].`，接著印出你的專案 ID。出現 `WARNING: You do not appear to have access to project` 代表專案 ID 打錯了。

## 步驟 1：建立防火牆規則

對應講義：「建立防火牆規則」的所有欄位。

```bash
gcloud compute firewall-rules create allow-quiz-helper-http \
  --network=default \
  --direction=INGRESS \
  --action=ALLOW \
  --rules=tcp:80 \
  --target-tags=quiz-helper \
  --source-ranges=0.0.0.0/0 \
  --enable-logging
```

每個參數對應講義的哪個欄位（講義第 7 節「VPC 防火牆規則的組成」）：

- `--network=default`：網路
- `--direction=INGRESS`：流量方向「輸入」
- `--action=ALLOW`：相符時執行的動作「允許」
- `--rules=tcp:80`：通訊協定和通訊埠
- `--target-tags=quiz-helper`：目標「指定的目標標記」
- `--source-ranges=0.0.0.0/0`：來源 IPv4 範圍，代表任何地方
- `--enable-logging`：「記錄」選「開啟」

**你應該會看到**：一個表格，`NAME` 是 `allow-quiz-helper-http`，`ALLOW` 是 `tcp:80`。

## 步驟 2：幫 VM 加上 quiz-helper 標記

對應講義：VM「編輯」→「網路標記」加上 quiz-helper。

```bash
gcloud compute instances add-tags quiz-helper-vm --zone=${ZONE} --tags=quiz-helper
```

## 步驟 3：再連一次

對應講義：重新整理小幫手的網址。

```bash
curl -s --max-time 5 http://${VM_IP}/healthz; echo
```

**你應該會看到**：`{"status":"ok","version":"v1"}`。小幫手恢復了，這次放行它的是 `allow-quiz-helper-http`。

## 步驟 4：找到連線記錄

對應講義：在記錄檔探索工具貼上查詢條件。記錄要一兩分鐘才會出現，可以先用手機開幾次小幫手。

在 Console 記錄檔探索工具，貼上這段查詢條件：

```
logName:"compute.googleapis.com%2Ffirewall"
jsonPayload.rule_details.reference:"allow-quiz-helper-http"
```

用指令查詢：

```bash
gcloud logging read \
  'logName:"compute.googleapis.com%2Ffirewall" AND jsonPayload.rule_details.reference:"allow-quiz-helper-http"' \
  --limit=3 \
  --format="table(timestamp, jsonPayload.connection.src_ip, jsonPayload.connection.dest_port, jsonPayload.disposition)"
```

- `logName:"compute.googleapis.com%2Ffirewall"`：防火牆規則記錄都寫在這個記錄名稱下
- `jsonPayload.rule_details.reference`：是哪一條規則記下來的
- `src_ip`：連線的來源 IP；`disposition`：`ALLOWED` 代表放行

**你應該會看到**：幾列記錄，`dest_port` 是 `80`，`disposition` 是 `ALLOWED`。其中一個 `src_ip` 是 Cloud Shell，用手機連的那幾筆是手機網路的對外 IP。
